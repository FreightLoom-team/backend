# Trucking System

Spring Boot project setup for the trucking system application.

- Java 21
- Spring Boot 4.1.2
- Maven (wrapper included — no Maven install needed)

Dependencies: Web MVC, Data JPA, Validation, Flyway, PostgreSQL driver, H2, Actuator, Lombok, DevTools.

## Run

```bash
./mvnw spring-boot:run
```

## Test

```bash
./mvnw test
```
